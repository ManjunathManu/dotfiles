# Git Commands
gs | git status | Show git repository status
gd | git diff | Show unstaged changes
gc -m "MESSAGE" | git commit | Create a commit with message
gp | confirm && git push | Push changes with confirmation
gpr | git pull -r | Pull with rebase
gl | git log --pretty --graph | Visual commit history
glo | git log --pretty --graph --oneline | Compact commit log
git checkout -b BRANCHNAME | git checkout | Create and switch to new branch
git branch -d BRANCHNAME | git branch | Delete local branch
git stash | git stash | Stash current changes
git stash pop | git stash | Apply most recent stash
git reset --soft HEAD~1 | git reset | Undo last commit, keep changes
git clean -fd | git clean | Remove untracked files and directories
